# 2.4 GHz Dipole Antenna

Dipole antenna design and simulation in Ansys HFSS, with a Jupyter notebook comparing ideal and tuned results.

- `dipole_2_4_ghz.aedt`: HFSS project.
- `dipole_antenna_design.ipynb`: design calculations and plots.
- `*.csv`: exported S11, impedance, gain, and directivity data.

Open the project in Ansys Electronics Desktop or the notebook in Jupyter. Keep the CSV files alongside the notebook.
